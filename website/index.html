The tie-out problem

Financial claims travel across documents. Their evidence should travel with them.

Figures move from source schedules into reports, presentations and valuation models. Small inconsistencies can survive unless the same metric, period and unit are compared across the pack.

01 / Consistency

Different figures

Revenue or EBITDA may differ between the CIM, QoE and model. DealTie highlights the spread and preserves each observation.

02 / Comparability

Different units

Currency, scale or period conflicts must be resolved before a tie-out is meaningful.

03 / Traceability

Missing source trail

Each confirmed observation carries a page, sheet or cell reference so a reviewer can return to the source.

Review workflow

From source files to an inspectable exception register.

Extraction assists the analyst. The analyst confirms what the figure means before DealTie compares it.

01 / Ingest

Load source files

Bring in PDF reports, Excel workbooks or a structured CSV evidence ledger.

02 / Confirm

Map observations

Confirm metric, period, value and unit. Retain the page, sheet or cell reference.

03 / Reconcile

Flag differences

Identify value mismatches, unit conflicts, missing values and incomplete coverage.

04 / Review

Export evidence

Inspect each source observation and export a structured evidence register.

Scope, without theatre

A narrow tool with explicit boundaries.

DealTie is an analyst-led financial evidence review prototype. It should earn trust through traceability and reproducibility, not broad claims.

SUPPORTED IN PROTOTYPE

Source intake

Selectable PDF text, Excel cell extraction and structured CSV, with manual confirmation and source references.

SUPPORTED IN PROTOTYPE

Deterministic checks

Value comparison, unit mismatch, missing values and source coverage. No automatic currency conversion or accounting interpretation.

NOT YET SUPPORTED

Production diligence

No scanned-PDF OCR, formula auditing, semantic matching, secure deal-room integration, multi-user permissions or audit-grade history.
