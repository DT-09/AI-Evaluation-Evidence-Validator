01 / The problem

Transaction documents drift. Reviewers need to see where.

A revised QoE report can change a headline metric. That figure may remain unchanged in a CIM, a valuation model or an investment committee presentation. DealTie makes those differences visible and traceable.

01 / CONSISTENCY≠

Numbers diverge

Compare selected metrics across documents and surface value, unit, coverage and evidence conflicts under explicit rules.

02 / VERSION CHANGE↗

Figures move

Compare two confirmed versions of a source document and identify exact downstream references that still show the previous figure.

03 / TRACEABILITY⌁

Evidence gets lost

Keep each observation connected to its document, version and page, sheet or cell reference for a reviewer to inspect.

02 / How DealTie works

A controlled process. An inspectable result.

DealTie separates extraction from financial interpretation. A person confirms what each source says; deterministic rules compare the confirmed observations.

STAGE 01

Ingest

Read supported PDF text, spreadsheet cells or a structured observation ledger. Preserve source locations.

STAGE 02

Confirm

Reviewers map extracted text to a metric, period, value and unit. Unconfirmed text is not treated as evidence.

STAGE 03

Reconcile

Compare exact metric-period groups using explicit tolerance rules. No silent currency or scale conversion.

STAGE 04

Trace impact

Compare source versions and list downstream values that may require review. Export the evidence handoff.

04 / Who it serves

Built around transaction review—not generic finance automation.

DealTie is designed for teams that repeatedly prepare, review or update multi-document financial transaction materials.

Who it's for

  • Boutique M&A advisory firms
  • Transaction advisory and financial due-diligence teams
  • Quality of Earnings providers
  • Corporate development teams reviewing acquisition materials

What it improves

  • Less manual cross-document comparison
  • Clearer evidence trail for every flagged observation
  • Faster identification of changed or stale references
  • Structured handoff for reviewer investigation and sign-off
Control boundary. DealTie does not decide which document is authoritative, interpret accounting policy, audit formulas, convert currencies or periods, or conclude that a discrepancy is an error. Human reviewers retain responsibility for financial interpretation and release decisions. The current prototype has no scanned-PDF OCR or semantic matching. It is not an audit opinion, and a flagged mismatch is not proof of an error.
05 / Product architecture

Purpose-built layers. No decorative AI claims.

The core is a deterministic evidence and comparison engine. The interface makes its inputs, rules and outputs inspectable. Advanced extraction and secure multi-user infrastructure remain separate engineering milestones.

Core engine

Python · Decimal arithmetic

Deterministic metric-period reconciliation, explicit tolerance, duplicate-source checks, version comparison and downstream reference classification.

Application

Streamlit · Analyst workbench

Document ingestion, analyst confirmation, evidence ledger, reconciliation and export workflows. Current application is a prototype.

Public product

HTML · CSS · JavaScript

Fast, accessible marketing pages and a local browser demonstration. Public CSV evaluation does not upload data.

Next engineering

API · PostgreSQL · encrypted storage

Planned foundation for authentication, tenant isolation, versioned records, access control and controlled retention. Not yet represented as live capability.

06 / Trust by design

Show the rule. Preserve the source. State the limit.

Financial review software earns trust by making its boundaries clear. DealTie avoids opaque scores and unsupported claims.

Deterministic rules

Same confirmed inputs and tolerance produce the same comparison. No hidden confidence score or automatic materiality judgement.

Evidence first

Each finding carries the supplied source observation and reference. Reviewers can trace what was compared.

Human authority

A flagged difference is not a confirmed misstatement. Qualified professionals determine meaning and appropriate action.

06 / Scoped review

A defined review, with an evidence-backed handoff.

For teams that need help applying the workflow to an authorised document set, DealTie can be discussed as a paid fixed-scope review. No public price or unsupported savings promise.

Defined scope

Up to 15 agreed metrics across up to three source documents, with source references where extractable.

Review outputs

Confirmed observation ledger, prioritised exception register, open questions and exportable review record.

Controlled close

One reviewer walkthrough and one correction pass against agreed acceptance criteria.
