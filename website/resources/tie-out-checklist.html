Pre-circulation financial tie-out checklist.

A practical checklist for a reviewer comparing selected headline figures across a CIM, Quality of Earnings report and valuation model. Use it to make the comparison set explicit before checking values.

1. Define what is being compared

2. Preserve the source evidence

3. Run and review the comparison

4. Prepare the handoff

Boundary: A discrepancy is an investigation lead—not proof of an error, misstatement, financial loss or recoverable amount. A tie-out does not constitute an audit, QoE conclusion, valuation opinion or transaction recommendation. This checklist is a working aid, not professional advice.
